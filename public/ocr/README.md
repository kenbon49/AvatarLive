OCR runtime assets for the live comment capture panel.

- `chi_sim.traineddata`: Tesseract `tessdata_fast`, Apache-2.0, https://github.com/tesseract-ocr/tessdata_fast
- `worker.min.js`: `tesseract.js` 7.0.0, Apache-2.0
- `tesseract-core-lstm.wasm.js` and `.wasm`: `tesseract.js-core` 7.0.0, Apache-2.0

These files are served locally so live recognition does not require a third-party CDN.
